# Fabric-Simulation-In-C-With-SDL2

Use WASD to move around and the mouse scroll to zoom in or out.
When holding down a mouse you can either move a "point" (nodes on which the fabric is built), throw it, or if you hadn't clicked on any points cut the fabric links
Press F to start creating a fabric link between points, E to remove a point, L to create a pinned point (not affected by any forces), U to create a normal point (affected by forces), T to freeze time and show exactly where the points are and press R to restart the simulation.
